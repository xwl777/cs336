* einops einops 是一个用“形状表达式”操作张量的库，常用于 PyTorch / NumPy / JAX / TensorFlow。它的核心价值是：把 reshape、transpose、squeeze、unsqueeze、repeat、mean/sum 这类操作写成更可读的形式。
	*   rearrange 它可以做 transpose、reshape、flatten、unflatten
	* reduce reduce 用来对某些维度做 mean、sum、max、min 等 ex. y = reduce(x, "b h w c -> b c", "mean")
	* einsum 可用于矩阵乘法
	* repeat  repeat 用来新增维度或沿某些维度复制。ex. y = repeat(x, "d -> b d", b=4)
* 数据格式
	* FP32
	* FP16（1+5+10）
	* BF16（1+8+7）
	* 混合精度 一般来说BF16用于参数、激活值、梯度，FP32用于优化器状态
* FLOPS开销
	* 对于一个简单的MLP层，前向传播的浮点运算次数是2 * B * D * D，反向传播的浮点运算次数是4 * B * D * D（需要计算激活值和参数两个梯度），共6 * B * D * D。因此，训练模型总的浮点运算次数约为6 * tokens * parameters。这同样可以用于transformer的估计，只要上下文长度不太大。
	* MFU 模型浮点运算利用率。即实际的浮点运算速度/显卡承诺的浮点运算速度。MFU与模型的架构有关。
* memory
	* 我们需要估算训练一个模型需要多少显存。考虑BF16用于参数、激活值、梯度，FP32用于优化器状态，使用AdamW优化器。参数需要2 * D * D * L比特，激活值需要2 * B * D *  L比特，梯度需要2 * D * D * L比特，而优化器状态需要8 * D * D * L比特
* 算术强度和加速器强度 数据必须从HBM中移动到计算核心中才能计算，而这需要大量时间开销
	* 算术强度 移动的每个比特平均进行的浮点运算数
	* 加速器强度 显卡每秒浮点运算数/显卡每秒传输比特数
	* 若算术强度 < 加速器强度，称为内存受限，反之称为计算受限
	* 不同的运算类型有不同的算术强度。一般来讲我们处于内存受限。大型矩阵乘法可能算术受限
